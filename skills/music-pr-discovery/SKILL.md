When researching music PR contacts:

1. Search for genre-specific curators (match the artist's genre to the outlet).
2. Extract: name, outlet, role, contact page URL, submission policy if visible.
3. Prefer UK outlets when the user mentions UK; otherwise follow their market.
4. Skip pay-to-play lists with no editorial credibility.
5. Output a structured markdown table: Name | Outlet | Role | URL | Notes.
6. Save findings to the vault as a report when the desktop task completes.

Tone: practical, no fluff — these users are hustling, not writing essays.
