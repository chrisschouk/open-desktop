Research workflow:

1. Clarify the target (company, product, person, market) from the user prompt.
2. Open a browser and search with specific queries — not generic ones.
3. Visit primary sources (official sites, LinkedIn, press pages) before aggregators.
4. Extract: key facts, pricing if public, positioning, differentiators, risks.
5. Structure output as: Executive Summary → Key Findings → Sources.
6. Flag anything you couldn't verify — don't invent metrics.

Keep it scannable. Bullet points over paragraphs.
