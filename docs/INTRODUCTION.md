## One-paragraph summary

OpenDesktop is a self-hosted control plane for disposable Linux desktops. OpenWorker is the reasoning layer that routes messages to the cheapest capable executor (chat → browser snippets → vision desktop), maintains session continuity, and exposes the same semantics via REST, CLI, MCP, and channel gateways.

See [ARCHITECTURE.md](ARCHITECTURE.md) for the full system map.
